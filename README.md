# Employee Raise Issue Portal

## 📌 Project Overview
The Employee Raise Issue Portal is a ServiceNow application that enables employees to raise workplace issues online and track their status until resolution.

## 🎯 Objectives
- Simplify issue reporting
- Reduce manual work
- Improve response time
- Track issue status

## ✨ Features
- Employee Login
- Raise Issue
- View My Requests
- Status Tracking
- File Attachments
- Email Notifications
- Admin Dashboard

## 🛠️ Technologies Used
- ServiceNow
- Service Portal
- Record Producer
- Flow Designer
- Business Rules
- Notifications

## 📂 Modules
### Employee Module
- Login
- Raise Issue
- View Status

### Admin Module
- View Requests
- Assign Issues
- Resolve Issues

## 🔄 Workflow
1. Employee logs in.
2. Employee submits an issue.
3. Ticket is created.
4. Issue is assigned.
5. Support team resolves the issue.
6. Employee receives notification.
